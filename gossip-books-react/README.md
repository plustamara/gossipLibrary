# Gossip Books — React Version

Same site, rebuilt as a proper React app with everything split into components and folders — the same way we structured the registration UI. Built with **Vite** (the standard, fast way to run React without heavy config). Still no backend: the quiz runs entirely in the browser, and "orders" route to your Instagram/phone/email in the Contact section.

## Folder structure

```
gossip-books-react/
├── index.html                 # Vite's entry HTML (loads fonts + mounts React)
├── package.json
├── vite.config.js
├── public/
│   └── images/                # put your real photos here
└── src/
    ├── main.jsx                # React entry point
    ├── App.jsx                 # assembles every section in order
    ├── index.css                # all styling (colors, layout — same fixes as before)
    ├── context/
    │   └── LanguageContext.jsx  # EN/AR toggle state, shared across every component
    ├── data/
    │   └── quizData.js          # quiz questions + result types — edit content here only
    └── components/
        ├── Navbar.jsx
        ├── Hero.jsx
        ├── Concept.jsx           # "Blind Date with a Book" section
        ├── FeatureCard.jsx       # reusable card (packaging, cup, bookmark, mandala)
        ├── Features.jsx
        ├── Quiz.jsx              # full quiz engine + QuizResult
        ├── Books.jsx
        ├── Mishkat.jsx
        ├── PricingCard.jsx       # reusable pricing card
        ├── Packages.jsx
        ├── MandalaCTA.jsx
        ├── ContactCard.jsx       # reusable contact info card
        ├── Contact.jsx
        └── Footer.jsx
```

Each section of the site is its own component file, and repeated UI (feature cards, pricing cards, contact cards) is broken into its own reusable component that takes props — so editing one card style updates every instance of it.

## Set up in VS Code

1. Install [Node.js](https://nodejs.org) (LTS version) if you don't have it — this gives you `npm`.
2. Open the `gossip-books-react` folder in VS Code: `File > Open Folder`.
3. Open the built-in terminal (`` Ctrl+` ``) and run:

```bash
npm install
```

This downloads React, Vite, and the few dependencies listed in `package.json` into a `node_modules` folder (not included here — that's normal, it's always regenerated by `npm install`).

4. Start the dev server:

```bash
npm run dev
```

5. Open the URL it prints (usually `http://localhost:5173`) in your browser. Changes to any file save and hot-reload instantly.

No GitHub setup here per your instructions — this is just the project files to run locally in VS Code.

## Where to make common changes

- **Quiz content** (questions, answers, result types): `src/data/quizData.js` only — never touch `Quiz.jsx` for content changes.
- **Colors, fonts, spacing**: `src/index.css`, all defined once at the top under `:root`.
- **Contact info**: `src/components/Contact.jsx`, in the two `<ContactCard>` calls.
- **Images**: drop real files into `public/images/` and reference them as `/images/yourfile.jpg` in `Concept.jsx` and `MandalaCTA.jsx` (currently using placeholder stock photos).
- **Adding a new section**: create a new file in `src/components/`, then import and place it in `App.jsx` wherever you want it to appear.

## Building for production (when you're ready to host it)

```bash
npm run build
```

This outputs a `dist/` folder of plain HTML/CSS/JS you can upload to any static host (Netlify, Vercel, GitHub Pages, or your own server) — whenever you're ready to set that up.
